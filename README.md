# JavaScript. Базовые задачи на работу с типами данных и алгоритмами

Сборник практических задач по JavaScript, выполненный в рамках обучения на курсе Skillfactory. Проект содержит решения алгоритмических задач, направленных на освоение базового синтаксиса языка, валидацию пользовательского ввода и работу со структурами данных.

##  Стек технологий
* **Language:** JavaScript (ES6+)

##  Реализованные задачи и изученные концепции

Примеры кейсов в репозитории:

1. **Калькулятор возраста с правильным склонением существительных (`calc_age`):**
   * Реализован расчёт возраста на основе текущего года (`new Date().getFullYear()`).
   * Написан алгоритм склонения слова «год/года/лет» в зависимости от последней цифры числа с использованием конструкции `switch(true)` и оператора остатка от деления (`%`).
   * Добавлена строгая валидация на пустые строки и проверку числового формата (`Number.isNaN`).

2. **Программа «Кредитный скоринг»:**
   * Реализована многоуровневая ветвящаяся логика (`if/else`) для определения лимита кредитования на основе возраста пользователя.
   * Написан алгоритм округления и проверки кратности запрашиваемой суммы (кратность 1000) с использованием методов `Math.floor`.
   * Покрыты основные сценарии ошибок ввода и превышения лимитов.

3. **Трансформация структур данных:**
   * Демонстрация работы со сложными объектами. Использование методов `Object.values()` и `Array.prototype.flat()` для преобразования свойств объекта и вложенных массивов в единый плоский массив данных.

4. **Базовые циклы и проверки:**
   * Обработка циклов `for` с предварительной валидацией входных данных на соответствие числовому типу (`!isNaN`).

##  Как запустить скрипты
1. Откройте консоль разработчика в браузере (F12 -> вкладка *Console*).
2. Скопируйте и вставьте код интересующей функции.
3. Протестируйте выполнение с помощью всплывающих окон `prompt` и `alert`.
